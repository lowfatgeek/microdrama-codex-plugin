# Examples

`DRAMA_001_sample` demonstrates the manual workflow for Episode 1 of a three-episode story.

It includes story concept, character psychology, GPT Image 2.5 character-sheet prompts, a Seedance 2.0-compatible `legacy-15s` generation plan, shot plan, storyboard prompts, Seedance prompts, and a compact final-pack example.

The sample intentionally uses `legacy-15s` so its three existing 15-second units remain a valid compatibility reference. For Seedance 2.5, use `controlled-15s` for the same layout or `long-form-30s` for a 30-second sequence followed by a 15-second sequence.

When creating real work, place it under `outputs/`, not `examples/`.
