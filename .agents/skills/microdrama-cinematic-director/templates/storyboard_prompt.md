# Storyboard Prompt Template

Use this template to create GPT Image 2 storyboard prompts from an approved shot plan.

## Output Format

```markdown
# Storyboard Prompts — Episode [Number]

## Storyboard Prompt — Block A

**Reference Images to Attach:**  
- Character sheet: [Character Name]
- Character sheet: [Character Name]

**Prompt:**

Create a vertical 9:16 cinematic storyboard collage with [5/6] panels based on the shot sequence below.

Use the provided character sheet reference images to maintain consistent face, hairstyle, outfit, age, body proportions, and emotional expression.

Visual style:
realistic Asian vertical microdrama film frames, Chinese microdrama cinematic style, emotional close-ups, dramatic but grounded lighting, cinematic depth of field, strong social-status contrast, realistic acting, luxury atmosphere when relevant, not comic, not manga, not cartoon.

Storyboard layout:
- cinematic collage
- chronological visual progression
- each panel clearly represents one shot
- panel count must match the shot count
- no speech bubbles
- no unnecessary text labels
- no manga panels
- no comic-book rendering
- no cartoon look

Character continuity:
[Insert concise character identity and wardrobe notes.]

Shot sequence:
Panel 1: [Shot 1 visual]
Panel 2: [Shot 2 visual]
Panel 3: [Shot 3 visual]
Panel 4: [Shot 4 visual]
Panel 5: [Shot 5 visual]

Composition:
vertical 9:16, cinematic framing, strong emotional readability, realistic facial expressions, clear body language.

---

## Storyboard Prompt — Block B

[Use the same format.]

---

## Storyboard Prompt — Block C

[Use the same format.]
```

## Required Rules

- Write storyboard prompts in English.
- Number of panels must equal number of shots.
- Use character sheet reference instruction.
- Maintain wardrobe and character consistency.
- Use cinematic realistic film-frame style.
- Do not use comic, manga, anime, cartoon, or infographic style.
- Do not include speech bubbles.
- Do not add unnecessary visible text.
- Do not create new story events beyond the shot plan.
