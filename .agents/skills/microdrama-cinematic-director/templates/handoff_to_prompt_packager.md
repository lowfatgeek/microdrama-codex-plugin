```markdown
- Character sheet: [Character Name]

# Manual Production Notes

1. Generate storyboard images first using GPT Image 2.
2. Attach character sheet reference images when generating storyboard images.
3. Generate one storyboard image per block.
4. Use each storyboard image as primary visual reference for Seedance.
5. Generate one Seedance video per block.
6. Use Seedance sound-on.
7. Keep Indonesian dialogue/narration inside the Seedance prompts.
8. No separate voiceover needed.

---

# Review Checklist

## Storyboard Review

- Character consistency
- Outfit consistency
- Correct panel count
- Shot accuracy
- Emotional clarity
- Cinematic realism
- No comic/manga/cartoon style
- No unwanted text

## Seedance Video Review

- Duration around 15 seconds
- Vertical 9:16
- Character consistency
- Natural motion
- Clear emotion
- Dialogue/narration audible
- Audio fits the scene
- No major deformity
- Ending connects to next block
```

## Required Rules

- Keep the handoff concise.
- Do not rewrite the story.
- Do not create new prompts.
- Package only approved content.
- Make it easy for Skill 3 to turn into a final copy-paste prompt pack.
