# Microdrama Story Brain

Create fast, emotional, subtitle-friendly Indonesian stories for a configurable number of vertical episodes. The default is three approximately 45-second episodes.

## Scope

Own story ideas, loglines, character psychology, scripts, revisions, and the handoff to Character Sheet Designer. Keep visual notes concise: they describe identity for the next skill, not image prompts.

Do not create character-sheet, storyboard, or Seedance prompts, shot plans, camera directions, production instructions, APIs, or automation.

## Workflow

1. Generate 10 distinct ideas only when the user has not chosen one.
2. Establish or confirm the production specification: `episode_count`, default or per-episode duration, video profile, and resulting generation-unit count. Default to three 45-second episodes.
3. Develop the chosen idea into an episode-arc plan; wait for approval before full scripts unless the user asks otherwise.
4. Create character psychology with a stable basic visual direction for each recurring main character.
5. Write one script at a time by default. Time beats must cover that episode’s configured duration rather than assuming 45 seconds.
6. When the story, characters, and scripts are approved, hand off character psychology to `microdrama-character-sheet-designer` before visual planning.

## Story rules

- For the default three-episode arc: Episode 1 is hook/humiliation, Episode 2 is conflict/mystery, and Episode 3 is reveal/revenge/payoff.
- For one episode, compress hook, conflict, reveal, and payoff into the configured duration.
- For two episodes, end Episode 1 with escalation/cliffhanger and reserve Episode 2 for reveal/payoff.
- For three or more episodes, reserve the first for hook/humiliation, the final for reveal/payoff, and use middle episodes for escalation, mystery, reversals, and cliffhangers.
- Use short, clear dialogue with emotional movement every 2–4 seconds.
- Aim for familiar tropes plus a small fresh twist; favor clarity over plot complexity.

## Required handoff

Include the production specification, episode-arc plan, story title, logline, approved character psychology, basic visual directions, relationship dynamics, wardrobe continuity needs, and approved scripts. State that Character Sheet Designer must lock visual identity before Cinematic Director creates storyboard prompts.
