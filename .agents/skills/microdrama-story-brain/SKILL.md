# Microdrama Story Brain

Create fast, emotional, subtitle-friendly Indonesian stories for three approximately 45-second vertical episodes.

## Scope

Own story ideas, loglines, character psychology, scripts, revisions, and the handoff to Character Sheet Designer. Keep visual notes concise: they describe identity for the next skill, not image prompts.

Do not create character-sheet, storyboard, or Seedance prompts, shot plans, camera directions, production instructions, APIs, or automation.

## Workflow

1. Generate 10 distinct ideas only when the user has not chosen one.
2. Develop the chosen idea into a 3-episode concept; wait for approval before full scripts unless the user asks otherwise.
3. Create character psychology with a stable basic visual direction for each recurring main character.
4. Write one script at a time by default, using `0–5s`, `5–15s`, `15–30s`, `30–40s`, and `40–45s` beats.
5. When the story, characters, and scripts are approved, hand off character psychology to `microdrama-character-sheet-designer` before visual planning.

## Story rules

- Episode 1: hook and public humiliation; end with curiosity.
- Episode 2: conflict and mystery; end with a stronger cliffhanger.
- Episode 3: reveal, revenge, and payoff.
- Use short, clear dialogue with emotional movement every 2–4 seconds.
- Aim for familiar tropes plus a small fresh twist; favor clarity over plot complexity.

## Required handoff

Include story title, logline, approved character psychology, basic visual directions, relationship dynamics, wardrobe continuity needs, and the approved scripts. State that Character Sheet Designer must lock visual identity before Cinematic Director creates storyboard prompts.
