```markdown
# Episode Review Checklist

## Storyboard Images
- Character consistency
- Outfit consistency
- Correct panel count
- Shot accuracy
- Emotional clarity
- Cinematic realism
- No unwanted text
- No comic/manga/cartoon style

## Seedance Videos
- Around 15 seconds per block
- Vertical 9:16
- Character consistency
- Natural motion
- Clear emotion
- Dialogue/narration audible
- Audio fits the scene
- No major deformity
- Ending connects to next block
```

## Packaging Rules

- This file is only for one episode.
- Do not include unrelated episodes.
- Keep Block A, B, C clearly separated.
- Make every prompt easy to copy manually.
