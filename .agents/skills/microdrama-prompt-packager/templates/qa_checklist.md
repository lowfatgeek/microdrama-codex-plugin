# QA Checklist Template

Use this checklist before finalizing a prompt pack.

## Story Structure QA

```text
- Story has a clear title.
- Story has a clear logline.
- Story is divided into 3 episodes.
- Episode 1 = Hook + Humiliation.
- Episode 2 = Conflict + Mystery.
- Episode 3 = Reveal + Revenge + Payoff.
- Each episode is designed for approximately 45 seconds.
```

## Character QA

```text
- Main character is clearly defined.
- Antagonist is clearly defined.
- Character psychology is clear.
- Character visual notes are consistent.
- Character sheet prompts are included if available.
- Character references are mentioned in storyboard prompts.
```

## Script QA

```text
- Each episode has an approved script.
- Dialogue is short and subtitle-friendly.
- Narration is clear and dramatic.
- Episode 1 ends with curiosity.
- Episode 2 ends with a stronger cliffhanger.
- Episode 3 delivers payoff.
```

## Shot Plan QA

```text
- Each episode is split into Block A, B, and C.
- Each block is 15 seconds.
- Default block has 5 shots.
- If using 6 shots, B-roll is justified.
- B-roll does not exceed 2 shots per block.
- Total duration per block remains 15 seconds.
```

## Storyboard Prompt QA

```text
- Each episode has 3 storyboard prompts.
- Each storyboard prompt is in English.
- Each storyboard prompt specifies vertical 9:16.
- Each storyboard prompt specifies cinematic storyboard collage.
- Each storyboard prompt mentions character sheet references.
- Panel count matches shot count.
- Prompt avoids comic/manga/cartoon style.
- Prompt avoids speech bubbles.
- Prompt avoids unnecessary text labels.
```

## Seedance Prompt QA

```text
- Each episode has 3 Seedance prompts.
- Each Seedance prompt is in English.
- Each Seedance prompt specifies duration: 15 seconds.
- Each Seedance prompt specifies vertical 9:16.
- Each Seedance prompt specifies image-to-video.
- Each Seedance prompt specifies sound-on.
- Each prompt uses storyboard image as primary visual reference.
- Indonesian dialogue/narration is included where needed.
- Audio instructions include ambience/music/SFX when relevant.
- Prompt does not introduce new story events.
```

## Final Packaging QA

```text
- Prompt pack is clean.
- Prompts are easy to copy.
- Sections are clearly separated.
- No unnecessary explanations.
- No missing episode.
- No missing block.
- No missing prompt.
```
