# Manual Production Checklist

1. Generate and approve one GPT Image 2.5 character sheet for every recurring main character.
2. Save approved sheets in `character_sheets/` using the filenames in the prompt pack.
3. Generate each storyboard or sequence board with the listed sheets attached.
4. Generate each Seedance unit from its matching board using the selected model and profile.
5. At every unit boundary, review face, hair, wardrobe, location, emotional state, and audio continuity.
6. Assemble the approved units manually in the preferred editor.
