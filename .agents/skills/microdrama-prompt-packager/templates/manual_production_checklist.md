# Manual Production Checklist Template

Use this checklist when manually producing videos from the final prompt pack.

## Step 1 — Generate Character Sheets

```text
- Open GPT Image 2 or preferred image model.
- Generate character sheet for each main character.
- Save each character sheet image.
- Use character sheets as reference images for storyboard generation.
```

## Step 2 — Generate Storyboard Images

For each episode:

```text
- Generate Storyboard Block A using its storyboard prompt.
- Attach relevant character sheet references.
- Review the result.
- Generate Storyboard Block B.
- Attach relevant character sheet references.
- Review the result.
- Generate Storyboard Block C.
- Attach relevant character sheet references.
- Review the result.
```

## Step 3 — Review Storyboard Images

Check:

```text
- Character consistency
- Outfit consistency
- Correct panel count
- Shot accuracy
- Emotional clarity
- Cinematic realism
- No unwanted text
- No manga/comic/cartoon style
```

## Step 4 — Generate Seedance Videos

For each episode:

```text
- Use Storyboard Block A image as reference.
- Paste Seedance Prompt Block A.
- Generate 15-second video.
- Review result.

- Use Storyboard Block B image as reference.
- Paste Seedance Prompt Block B.
- Generate 15-second video.
- Review result.

- Use Storyboard Block C image as reference.
- Paste Seedance Prompt Block C.
- Generate 15-second video.
- Review result.
```

## Step 5 — Review Seedance Videos

Check:

```text
- Duration around 15 seconds
- Vertical 9:16
- Character consistency
- Natural motion
- Clear emotion
- Dialogue/narration audible
- Audio fits the scene
- No major deformity
- Ending connects to next block
```

## Step 6 — Manual Editing

```text
- Combine Block A, B, and C into one 45-second episode.
- Add subtitles if needed.
- Keep Seedance native audio unless you intentionally want to edit audio.
- Export vertical 9:16 video.
```

## Step 7 — Repeat for Episode 2 and 3

```text
- Complete Episode 1 first.
- Then produce Episode 2.
- Then produce Episode 3.
```
